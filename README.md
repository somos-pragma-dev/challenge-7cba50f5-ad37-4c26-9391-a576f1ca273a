# Diseño de Componentes Accesibles

El equipo de desarrollo necesita crear componentes de interfaz de usuario accesibles utilizando Angular y el Material Design System. El objetivo es garantizar que los componentes sean utilizables por personas con discapacidades visuales, auditivas y motoras. Los componentes deben ser compatibles con lectores de pantalla y seguir las mejores prácticas de accesibilidad.
